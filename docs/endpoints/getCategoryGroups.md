# List category groups

`GET /api/external/v2/category_groups`

This endpoint returns a list of category groups

> ℹ️
> This endpoint requires one of the following scopes: `categories:all`, `categories:readonly`

[Source Pennylane](https://pennylane.readme.io/reference/getcategorygroups) · [Index du SDK](../operations.md)

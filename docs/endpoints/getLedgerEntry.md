# Retrieve a Ledger entry

`GET /api/external/v2/ledger_entries/{id}`

Retrieve a ledger entry


> ℹ️
> This endpoint requires one of the following scopes: `ledger_entries:readonly`, `ledger_entries:all`

[Source Pennylane](https://pennylane.readme.io/reference/getledgerentry) · [Index du SDK](../operations.md)

## Appel Go

```go
GetLedgerEntryWithResponse(ctx context.Context, id int, params *GetLedgerEntryParams, reqEditors ...RequestEditorFn) (*GetLedgerEntryResponse, error)
```

## Entrée

| Paramètre HTTP | Argument Go | Emplacement | Type | Présence | Utilisation |
|---|---|---|---|---|---|
| `id` | `id` | path | integer | obligatoire | The unique identifier of the ledger entry<br>example `42` |
| `X-Company-Id` | `params.XCompanyId` | header | string | facultatif | Numeric ID of the company to act on. Required when authenticating with a firm token. Ignored when the token is already bound to a company.<br>example `"12345"` |

Aucun corps de requête.

Ledger entry details

| `$.updated_at` | string (date-time) | obligatoire | Last update<br>example `"2023-08-30T10:08:08.146343Z"` |
